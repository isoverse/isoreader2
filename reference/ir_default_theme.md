# Default isoreader2 plotting theme

Default isoreader2 plotting theme

## Usage

``` r
ir_default_theme(text_size = 16, facet_text_size = 20)
```

## Arguments

- text_size:

  base font size in points (default: `16`)

- facet_text_size:

  font size for facet strip labels in points (default: `20`)

## Value

a `ggplot2` theme object
